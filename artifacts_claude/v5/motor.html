Decisions

  1. Hero flip. Today the left form stack (Position/Jog/Absolute cards) crowds the stage view behind a 360/560 splitter seed. v5: truth column 290 px, stage view takes the rest, commands leave the column entirely.
  2. One command tray. Jog cross, step presets, absolute move, Home/Zero — one horizontal surface in strip material. Motion commands are amber (outline = request, fill = primary), matching the planner's MOVE STAGE spine.
  3. Truth over furniture. Position readback, homed state, limit state and motion state are chips/tiles that never scroll away. Limit switches on GRBL aren't decoded (TODO manual) — UNKNOWN rung, dashed, with caption.
  4. Zero-here honesty. The frame card shows the user↔machine origin mapping — the class of bug Kaya caught (stage view fed machine-frame limits after Zero Here) becomes visible at a glance.
  5. Light theme: the position readout follows panel surface tokens (it is not a plot); only the stage view keeps the instrument-well dark canvas with bezel.

Law compliance

  • Motion is amber everywhere — jog, move-to, moving chip, planner spine (law 2).
  • Red appears only on STOP while motion is live (fail-safe stop class).
  • UNKNOWN limits render dashed-neutral, never green "OK", never red (law 8).
  • Quiet nominal: idle panel is grey + one accent position marker (law 1).
  • No effects on the stage-view plot; bezel is flat tokens only (law 8/perf).
