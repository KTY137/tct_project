Decisions

  1. Two sheets, one banner. Wavegen (readable, commandable) and PDL record card (hand-knobs, metadata only) are separate surfaces so nobody mistakes a record for a control (law 7).
  2. UNKNOWN, not red. Both live violations fixed by taxonomy: unknown output/emission are dashed-neutral with "?", red stays reserved.
  3. Amber output. Enabling the wavegen output arms the photon path — motion/armed class. The DangerGate confirmation on enable stays.
  4. Duty-cycle sanity caption stays under the sheet (physics guard against pulse-width/frequency combinations that melt things).
  5. Routing card. New: one line showing wavegen → head → scope CH1 — the mental model that today lives only in the operator's head.
