The kill-switch escalation (Paul's ruling)

⏻ All outputs off OFFLINE — nothing to kill
→
⏻ All outputs off connected · output off — ready, inert
→
⏻ All outputs off HV LIVE — one tap, instant, no latch
Law 5: fail-safe stops are one-tap. Law 1/2: red is never standing chrome — it arrives with the volts and leaves with them.

Decisions

  1. Measured, not commanded. The hero number is the readback. When the driver can't read the output bit (ISEG decode: TODO manual), HV state shows the dashed UNKNOWN rung — never a confident "OFF" that might be false-safe.
  2. Two reds max, both earned. Kill switch + HV state carry red only while volts exist. The audit's two filled-red slabs on a disconnected panel drop to ghost/neutral outlines.
  3. Codex's red tray rejected. Paul flagged the "red-accented DangerGate tray pinned to bottom" as a law-1/2 violation — the envelope summary joins the ramp card, colored only while armed/live.
  4. FormSheet grammar. Compliance/ramp/polarity become intrinsic-width right-aligned rows; the "LIMIT OK" full-width bar dies (limit state is a caption on the Compliance tile).
  5. Multi-channel honest. The channel rail lists real channels with ladder dots; with one channel it collapses — no nested-tab furniture.

Law compliance

  • Red = HV-live/trip/abort exclusively; disconnected panel is fully quiet (laws 1/2).
  • Kill switch one-tap, no latch — it can only make things safer (law 5).
  • Unreadable output bit → UNKNOWN rung, never assumed OFF (law 8).
  • Mono numerals, measured vs setpoint always labeled apart (laws 3/7).
  • Ramp start remains DangerGate-confirmed; envelope covers in-scan ramps (§11).
