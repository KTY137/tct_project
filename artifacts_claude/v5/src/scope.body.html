Decisions

  1. Measurements drawer follows acquisition. Open while LIVE/SINGLE runs, collapsed when idle — Jonathan's correction to Codex's "closed by default": a physicist aligning the beam needs the live numbers.
  2. Header tiles, not floating HUD. Amplitude/Rise/Charge/Drift sit in the card header band. The trace pixels stay 100% visible at all times.
  3. Rail overflow fixed structurally. Fixed 280-px rail, eliding text, FormSheet rows — the audit shows truncated headers and clipped capsules ("LIVE RE…", cut DUT tiles) from shrink-to-clip layout.
  4. Empty state (offline): axis frame survives at the configured timebase/V-div (they are real instrument settings); grid + trace drop; dim canvas + "No live trace — scope offline". No more fake −200…200 ns.
  5. Cursor readout is an opaque chip — exact-value reads need a contrast floor; translucency has none over an arbitrary trace.
