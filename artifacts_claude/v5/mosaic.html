How it works

  1. It is a scan. Same move→settle→grab loop as every routine; the planner's Capture photo block is the same primitive. v1 ships as a procedure in the Camera panel (like the repeatability test); a planner-native mosaic routine follows free.
  2. Stitching v1 = calibrated placement. Tiles land at their known stage positions via px→mm; overlaps linear-blend. v2 refines seams with the sub-pixel phase correlation already shipped for repeatability.
  3. Safety unchanged. Motion = amber, DangerGate confirmation before the raster, STOP always visible, envelope = the chosen area. Laser state is irrelevant-but-recorded (illumination note in metadata).
  4. Deliverable: one TIFF/PNG + JSON sidecar (tile positions, exposure, timestamp, px→mm cal id) — reproducible, citable in the logbook, usable as a base layer under scan maps later.

Law compliance

  • Raster start is DangerGate-confirmed; motion amber; STOP red while moving (laws 2/5, rule 2).
  • Preconditions honest — no capture without homed + calibrated (law 8).
  • Pending tiles hatched, never faked; seams from real data only (law 7).
  • Implementation stays with the crew (devices/motion) + Mary review — not a free-lane task.
