The hardware state ladder

Paul's canonical taxonomy — every chip, dot, banner and well in the app draws from this single ladder. The live audit found red spent on harmless states (camera offline, output-unknown) and green on nominal ones (saved, valid, load) — the ladder eliminates both by construction.

OFFLINE — faint solid CONNECTING — one pulse SIM — hatched cyan ring IDLE — muted, no color ACTIVE·motion — amber ACTIVE·HV-live — the only steady red ACTIVE·benign — accent UNKNOWN — dashed, never red, never a fill TRIPPED — red + one pulse

UNKNOWN is the load-bearing new rung: the bias output bit, manual-laser emission and GRBL limit switches are genuinely unreadable today — the UI says so instead of guessing (law 8), and never paints unknown as danger.

Six ratified pillars

  1. Chrome collapse. Band + strip own navigation, global commands, device state and run numbers. Toolbar, ribbon, breadcrumb and duplicate status bar die; the QML shell becomes the default. (Noah §1 — mostly QML recomposition, zero Python signal changes.)
  2. Glass is faked, honestly. Prometheus's research: Apple itself collapses vibrancy to opaque under "Reduce Transparency" — our pre-blended QSS chrome/strip/edge tokens already deliver the material. Real blur only ever as a snapshot-once QML effect on the static outer chrome; plots, camera and maps stay fully opaque; DWM Mica skipped.
  3. The settings-pane grammar. New settings_row + FormSheet in panel_kit: sentence-case label left, intrinsic-width right-aligned mono value, muted unit — content capped at ~560 px. Kills the 1200-px field for "1000.00 Hz" in every config panel at once.
  4. One designed offline state per panel. New StateStack: page 0 live content, page 1 the themed EmptyState. Kills seven "NO FRAME YET" capsules, four grey "NO …" chips, fake 0.1–0.9 axes, and the Monitor's "All nominal" with zero readings — per Jonathan's rule, an axis frame survives only where the axis is a real instrument setting (scope timebase), never derived from missing data.
  5. The instrument well. Dark plots are a ratified law (viridis data ink) — in light theme they currently read as pasted holes. v5 frames every plot ONCE inside FigureCard: hairline bezel, 3-px rounding pad, glass header, flat static shade strip. No shaders, no per-side borders on hot paths (guard test pins this).
  6. Numbers live in exactly one place. Abel: the run strip owns State/HV/Progress·ETA/Position; the scan map overlay is spatial only (cursor, trail, sub-phase eyebrow) — nothing double-reports. Jonathan: charge displays switch to fC (1 MIP @ 300 µm ≈ 3.6 fC — today's "0.004 pC" tiles read as zero); pC stays the storage unit.
