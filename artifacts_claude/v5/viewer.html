The empty state (kept, made canonical)

🗺
No run in progress
Configure and start a routine in the Scan Planner. Progress, ETA and position will appear in the status strip.

One designed panel-level state (StateStack) — the four "NO RUN YET" capsules die; they were four facets of one absent run. No fake axes: the map extent comes from the plan, so no placeholder extent is invented.

Decisions

  1. Single source per quantity. State, HV, Progress·ETA·elapsed and Position live in the shell strip (which travels with a detached viewer). The old bottom tile row dies — it double-reported the strip.
  2. Spatial-only overlay. The map shows where: live cell cursor, snake trail, stale/empty canvas, plus the sub-phase eyebrow. Codex's floating numeric HUD was rejected by both Jonathan (viridis legibility) and Abel (double-reporting).
  3. Glass corner controls. Pause/Abort return to the map's letterbox margin on an opaque backing plate — reachable without leaving the hero, outline→filled red discipline, same coordinator path as the strip Abort.
  4. Mid-run charge glance. Jonathan's addition: the current-point charge (fC) joins the strip's Progress caption during a run — catches a dead channel without switching to the Scope tab.
  5. Paused/aborted states designed. PAUSED: cursor stops, quiet amber caption (+ excursion reason on WARN-hold). ABORTED: map retained, stale-dimmed, neutral banner "N/M points saved · file flushed" — red is the action, never the resting result.
