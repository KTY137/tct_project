Decisions

  1. Two cards, one rhythm. Method (a settings pane that stamps run metadata) and Repeatability (a procedure with a result). Nothing else — the four show/hide method groups collapse into the method row's own contextual rows.
  2. Motion procedure is amber. The repeatability test moves the stage — it carries the motion class and an explicit precondition chip; it never runs without homed + camera (and remains DangerGate-confirmed).
  3. Results with a timestamp. σ values as chips + date; a stale result is visibly old rather than silently trusted (law 4).
  4. De-capsing. Body prose and labels go sentence case; caps-mono is reserved for eyebrows and quantities (typography rule, all panels).
