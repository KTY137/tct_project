Seven laws

ratified by the design council

Every future panel obeys these or doesn’t merge. They are the anti-jungle.

01 · Quiet nominal

Grey is the color of “everything is fine.” Saturated color exists only for abnormal, live-dangerous, or actively running states (ISA-101). Green is spent sparingly; the accent never means “good.”

02 · Command classes, not one red

Red appears only on HV energization, trips, and Abort. Motion commands are amber-gated, laser output is amber/neutral, disconnect is grey. A scan start that ramps HV is amber with its HV line called out red in the envelope — it never borrows abort styling.

03 · Numbers are mono, prose is quiet

Every physical quantity: mono, tabular, unit subordinated. Labels: tiny tracked mono engraving. Explanations: sentence-case sans — never uppercase prose.

04 · Staleness is designed

No raw “--”. A tile that has nothing to say is stale (dimmed, desaturated) with a caption that says why: not connected, no run, last value aged. Data ink never silently freezes.

05 · Two-step arm, instant stop

Danger is a latch: Arm (hold or press-twice — keyboard parity, glove-reliable) over the full envelope text, then a visible armed state with timeout, then Execute. Wired through DangerGate; separate gates for HV, motion, laser. Abort never holds.

06 · Simulation can never pass as real

Simulated devices wear a hatched-cyan ring, a persistent ribbon, and a plot watermark — a screenshot is self-evidently sim. Sim never borrows green, and sim-marking is cyan’s only chrome job (otherwise cyan lives in colormaps, never decoration).

07 · The UI never lies about hardware

Show measured, not wished: setpoint and readback labeled apart; unknown states say “unknown” (never a stub value); no control implies an ability the driver lacks — the manual laser has no software switch, so the UI shows none.

08 · Motion is a scarce signal

Values update, they don’t animate. State transitions ease over ~200 ms; only live states may pulse; one attention pulse for a new critical alarm. Nothing decorative moves.
